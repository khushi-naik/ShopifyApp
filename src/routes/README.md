# Routes

This project uses TanStack Start file-based routing. See the [root README](../../README.md)
for prerequisites, installation, development, and validation commands.

## Current routes

| File | URL | Purpose |
| --- | --- | --- |
| `__root.tsx` | Root layout | Provides the document shell, shared styles, and route outlet. |
| `index.tsx` | `/` | Runs the Room Match flow: photo selection, room analysis, shopping brief, recommendations, cart, and demo checkout. |

## Route conventions

- Add pages as route files under `src/routes/`; nested folders create nested
  paths.
- `__root.tsx` is the app shell and must keep its `<Outlet />` so child routes
  can render.
- `routeTree.gen.ts` is generated by TanStack Start. Do not edit it by hand.
